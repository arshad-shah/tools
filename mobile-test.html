🔧 Mobile Drag & Drop Debug Guide

🚀 Testing the SortableList Component

Follow these steps to test mobile drag and drop functionality:

Step 1: Start Development Server

In PowerShell, navigate to your project directory and run:

cd "c:\Users\shaha\OneDrive\Code\tools"; pnpm dev

Step 2: Open in Mobile Browser

Access your app at http://localhost:5173 on:

  • 📱 Physical mobile device (connected to same network)
  • 🖥️ Desktop browser with mobile device simulation (F12 > Toggle Device Toolbar)

Step 3: Test Drag Functionality

Navigate to a page that uses SortableList (like PDF Merger) and test:

  • Touch & Hold: Press and hold on drag handle for 150ms
  • Drag: Move your finger while holding
  • Drop: Release to drop item in new position

🔍 What We Fixed:

  • Touch Sensor: Reduced delay from 200ms to 150ms
  • Touch Tolerance: Increased from 8px to 12px for better mobile precision
  • Touch Targets: Increased minimum size from 36px to 44px
  • CSS Touch Action: Added proper touch-action styles
  • Visual Feedback: Improved opacity and scaling for mobile

📱 Mobile-Specific Features:

  • Fallback Buttons: Up/Down chevron buttons for devices where drag doesn't work
  • Larger Touch Areas: 44px minimum for better accessibility
  • Visual Indicators: Drag handle is more visible on mobile

🐛 Debugging Console Output

Console Logs Added: Check browser console for drag events:

  • Drag start: [item-id] - When drag begins
  • Drag end: [from] -> [to] - When drag completes
  • Reordering from index [X] to [Y] - When items reorder

⚠️ Common Mobile Issues & Solutions

Issue: Touch events not registering

Solution: Added touch-action: none to drag handles

Issue: Scrolling interferes with dragging

Solution: Used touch-action: manipulation on containers

Issue: Small touch targets

Solution: Increased minimum touch target size to 44px × 44px

Issue: Drag sensitivity too low

Solution: Reduced activation delay and increased tolerance

Still having issues? Try the mobile reorder buttons (up/down arrows) as a fallback method.

🔧 Advanced Configuration

You can now customize touch behavior using the touchConfig prop:


<SortableList
  touchConfig={{
    delay: 100,      // Faster activation
    tolerance: 15    // More tolerance for shaky hands
  }}
  // ... other props
/>
