# Cynosure gaps found by the tools redesign

What tools needs that `@arshad-shah/cynosure` 0.6.0 does not have, where it
showed up and what tools does meanwhile. Each gap is fixed in Cynosure, not
worked around for good here (redesign spec, rule 3).

| #   | Gap                                                                                                                                                                                                                                            | Where                                                                                                              | Meanwhile in tools                                                                                                                                                                                                    |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `useColorMode` and `ThemeToggle` do not follow a mode chosen in another tab (no `storage` event listener).                                                                                                                                     | Theme (`src/app/Theme.tsx`)                                                                                        | Nothing: other tabs keep their mode until reloaded. Not hand-rolled, on the owner's instruction.                                                                                                                      |
| 2   | With nothing saved, `themeInitScript` leaves `<html>` unmarked and the stylesheet gives an unmarked root no `color-scheme`, so a dark-OS visitor sees light until `CynosureTheme target="document"` mounts and sets `data-cy-mode="system"`.   | First paint (`public/theme-init.js`)                                                                               | `tokens.css`: `:root:not([data-cy-mode]) { color-scheme: light dark; }`. Cynosure could ship that rule, or have the script mark `system`.                                                                             |
| 3   | No router integration outside SideNav: `Link`, `Button href`, `Card href`, `ListRow href` and `Breadcrumbs` render plain anchors with no `renderLink` (Breadcrumbs only has `onClick`).                                                        | Every page link                                                                                                    | `src/app/shell/use-client-links.ts` turns plain left clicks on same-origin anchors into router navigations; Breadcrumbs use `onClick` + `preventDefault`. A `LinkProvider` (or `renderLink` on each) would remove it. |
| 4   | `CommandPalette` takes a fixed `commands` list: no `onQueryChange` for commands built from the query, recently run commands live in component state only (no `recent`/`onRecentChange` to persist them), and `disabled` cannot carry a reason. | Mod+K (`src/app/shell/AppPalette.tsx`)                                                                             | Tools keeps its own recent list (`tools:recent-commands`) and passes it as a "Recent" group with `recentLimit={0}`; no source uses the query today.                                                                   |
| 5   | No form primitive: nothing submits a group of fields on Enter or names the group as a form.                                                                                                                                                    | Password for an encrypted PDF (`src/pdf/ui/PasswordForm.tsx`), JWT verify key                                      | `onKeyDown` Enter on the field.                                                                                                                                                                                       |
| 6   | Light palette: `--cy-color-accent-text` on `--cy-color-soft` is 4.34:1 for the tools accent (under AA 4.5:1).                                                                                                                                  | Old tools' accent text on selected rows (`test/tokens.contrast.test.ts`)                                           | The test allows 4.2:1 for that pair until Cynosure's derivation keeps 4.5:1.                                                                                                                                          |
| 7   | `AppShell` has no place for a brand above the navigation column and no built-in collapse for the desktop rail (SideNav's `collapsed` must be held and toggled by the product).                                                                 | Shell                                                                                                              | The logo sits at the start of the top bar; the rail toggle is an IconButton there, its state in tools' `app-nav` store.                                                                                               |
| 8   | `SideNav` `footer` takes only nav entries, so a `Menu` (Help) or `ThemeToggle` cannot sit in it.                                                                                                                                               | Navigation footer                                                                                                  | They sit in an `Inline` under the SideNav, in the same column.                                                                                                                                                        |
| 9   | `useCynosureTheme().colors` resolves only Cynosure's roles. Product colour roles built on them (tools' `--chart-*`, `--syntax-*`, aliased roles with `color-mix()`) have no resolver for canvas code.                                          | Charts, diagrams, markdown export (not yet redesigned)                                                             | `src/shared/ui/adapters/resolve-colour.ts` reads a role as a computed colour; the readers re-read on `useCynosureTheme().palette`. Goes when those tools are redesigned on Cynosure's colours.                        |
| 10  | No PDF page thumbnail: a page rendered elsewhere (a worker bitmap) can only be shown as an `Image` from an object URL.                                                                                                                         | PDF Merger file list                                                                                               | `src/pdf/ui/use-first-page-image.ts` encodes the worker's bitmap to a blob URL for `Image`.                                                                                                                           |
| 11  | `Tabs` throws when its effects run twice (React StrictMode in development, and a page kept alive with React `Activity` and shown again): the tab strip's context menu calls `onOpenChange` without its item and reads `.value` of undefined.   | JWT Decoder sections                                                                                               | A `SegmentedControl` (three short sections, which the spec allows) with the section rendered below it.                                                                                                                |
| 12  | `TextArea` (and `TextField`) has no monospace option for code, tokens and generated secrets.                                                                                                                                                   | JWT token input, Header and Payload JSON in the builder                                                            | The proportional font.                                                                                                                                                                                                |
| 13  | `SplitPane` cannot stack its panes on a narrow container; the product must pick between it and a `Stack` itself.                                                                                                                               | JWT Decoder (transform pattern)                                                                                    | `useMediaQuery('(min-width: 1200px)')` chooses SplitPane or Stack.                                                                                                                                                    |
| 14  | `Checkbox` has no card variant with a picture (`RadioGroup` has `variant="card"` with `media`), so a grid of pages to tick cannot make the whole thumbnail the target.                                                                         | PDF Splitter, `src/pdf/ui/PageGrid.tsx`                                                                            | Each page is a `Card` with the page `Image` and a `Checkbox` under it.                                                                                                                                                |
| 15  | `Checkbox` `onChange` gives only the new value (no event), so a grid of checkboxes cannot do Shift-click range selection.                                                                                                                      | PDF Splitter page selection                                                                                        | `PageGrid` notes `shiftKey` from the press (pointer or key) in a capture listener and passes it with the change.                                                                                                      |

| 17  | `Image` cannot carry an overlay (a guide drawn over the picture).                                                                                                                                                                              | Favicon Generator's maskable icon previews (the 80% safe zone)                                                     | The safe zone is said in words under the previews.                                                                                                                                                                    |
| 18  | `CompareSlider` sizes only native `img`, `video` and `canvas` layers (its stylesheet targets them); a Cynosure `Image` as `before` or `after` is not laid out like the other side, so the two pictures do not line up.                         | Image Compressor's Compare card                                                                                    | Each side is an `Image` with the original's ratio in a one-column `Grid`; the sides still drift apart. Needs `CompareSlider` to take `Image` (or `src`s) directly.                                                    |
| 19  | No file-picker button: picking a file means a `FileDrop` zone, which is too heavy as one action among Paste and Clear under a text input.                                                                                                      | Open file under every transform input (`src/app/ui/text-source.tsx`)                                               | A `Button` that clicks a `hidden` `FileInputBase`. A `FileButton` (or `FileDrop variant="button"`) would replace it.                                                                                                  |
| 20  | `TextArea` takes no dropped files (no `onFiles`), so text tools cannot open a file dropped on their input.                                                                                                                                     | Every transform input                                                                                              | Open file (gap 14); Base64 also shows a small `FileDrop`.                                                                                                                                                             |
| 21  | `CodeBlock` renders all of `code`: no virtualisation or built-in "show the first N" for very long output (megabytes of Base64, hex dumps).                                                                                                     | Base64 result, decoded bytes                                                                                       | Tools pass a preview (64 KB, 4 KB of bytes) with a note; Copy and Download take all of it.                                                                                                                            |
| 22  | No bit field: a row of toggle buttons for the bits of a word, grouped by byte, with one tab stop.                                                                                                                                              | Number Base Converter bit grid                                                                                     | `src/tools/number-converter/components/BitGrid.tsx`: square `Button`s with `aria-pressed` in an `Inline`, `useRovingFocus` for the arrows.                                                                            |
| 23  | `Table` cannot tint a cell or a column (no per-cell tone or column highlight), so a heat grid such as working hours cannot be shaded.                                                                                                          | Epoch Converter meeting planner                                                                                    | Working hours are `Badge`s in their cells, best-overlap columns have a success `Badge` header, and a `Notice` names them.                                                                                             |
| 24  | `Combobox` shows an empty input for a `value` set from outside until the user types (it needs `inputValue` kept by the product).                                                                                                               | Time zone pickers (Epoch Converter)                                                                                | A `Select` of every zone, with type-ahead.                                                                                                                                                                            |
| 25  | No syntax colours: `CodeBlock` takes a `highlight` render, but Cynosure has no token roles (keyword, string, number…) a product highlighter can colour with, and product CSS is not allowed.                                                   | Code Formatter output, JSON in Base64 decode                                                                       | Plain CodeBlocks with line numbers; tools' tokenizer is unused there until Cynosure has syntax tokens (or a highlight that returns token kinds).                                                                      |
| 26  | `QRCode` takes no colours, logo (with cleared modules) or quiet-zone size from props, and cannot hand back SVG or PNG for export, so it cannot draw a user-styled code.                                                                        | QR Code Generator preview and export                                                                               | The tool's renderer (`lib/render.tsx`, qrcode.react behind `src/shared/ui/adapters/QrCode`) makes the SVG or PNG and the preview shows it as an `Image`: what you see is what downloads.                              |
