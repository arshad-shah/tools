# Cynosure gaps found by the tools redesign

What tools needed that `@arshad-shah/cynosure` 0.6.0 did not have, where it
showed up and what tools does meanwhile. Rows marked **Fixed in 0.7.0** say
what tools uses now; rows marked **Cynosure 0.8.0** are being built there. Each gap is fixed in Cynosure, not
worked around for good here (redesign spec, rule 3).
